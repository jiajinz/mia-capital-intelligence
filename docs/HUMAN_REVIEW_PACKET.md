This independent portfolio project has no affiliation with MDAD or HNTB. These are unapproved review candidates from two selected Exhibit B reports. All paired examples remain held. The source files and exact checksums are in data/source_inventory.json.

## How to inspect

Run the Stage 1A CLI with --project and the exact token below. Inspect its two separate source observations, physical row locators, original metric header and raw amount. The report has no change calculation. The excerpts here fold description line breaks for readability and show parsed original estimates in USD. Earlier and later refer to the memo coverage periods, with project data freeze dates still unknown.

For pairs, a human may retain held, document comparable for a named metric with all required evidence, or document excluded with a reason. Identical amounts provide no approval. For one-sided rows retain the earlier-only/later-only presence observation and ask the listed question. See REVIEW_DISPOSITIONS.md for the schema and procedure.
